# PNC Virtual Wallet Statement Parser

This Python script extracts and parses transaction data from PNC Virtual Wallet PDF statements, making it easier to analyze and organize your financial records.

## Features

- Extracts transaction details from PNC Virtual Wallet PDF statements.
- Outputs the data in a structured format (e.g., CSV) suitable for financial analysis or importing into accounting tools.

## Requirements

-INP

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/PragmaticsGhost/PNC_VW_Parser.git
   ```

2. Navigate to the project directory:

   ```bash
   cd PNC_VW_Parser
   ```

## Usage

1. Make sure your PNC Virtual Wallet statements are in PDF format.

2. Run the script by providing the path to your PDF statement:

   ```bash
   python PNC_VW_Statement_Parser.py /path/to/statement.pdf
   ```

3. To save the parsed data to a file, redirect the output to a CSV file:

   ```bash
   python PNC_VW_Statement_Parser.py /path/to/statement.pdf > output.csv
   ```
